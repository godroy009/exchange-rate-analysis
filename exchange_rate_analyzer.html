ℹ️ About

Project overview and learning objectives

This project demonstrates data extraction from an API using the Frankfurter Exchange Rate API. The retrieved JSON data is converted into structured data and analyzed using statistical calculations and visualizations.

It serves as a practical example for a college Data Science practical, showcasing real-world data engineering techniques in the browser.

Key Demonstrations

📡 API Data Extraction 🔄 JSON Processing 📊 Data Analysis 📈 Data Visualization ⬇️ CSV Export 🔍 Search & Sort 🧮 Statistical Calculations 🌐 Responsive Design
